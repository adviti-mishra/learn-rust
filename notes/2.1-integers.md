
# 2.1: Integers 
## Types, part 1 

### Primitive types: 

```
u32: unsigned 32-bit integer 
i32: signed 32-bit integer
```
same for 8,16,32,64,128 bits

#### Bit width: 

```
u32: 0 - 2^31 - 1 
     (u32::MAX)
i32: -2^31 - 2^31 - 1 
     (i32::MIN - i32::MAX)
     note: 1 bit is used to represent the sign
```

### Literals

#### Type?
The Rust compiler will try to infer the type of a literal based on how it's used. 

If you don't provide any context, the compiler will default to i32 for integer literals. 

```
Note: If you want to use a different type, you can add the desired integer type as a suffix—e.g. 2u64 is a 2 that's explicitly typed as a u64
```

#### Underscore 
```
Note: you can use _ to improve readability of large numbers. eg: 1_000_000 is the same as 1000000 
```

### Arithmetic operators 
PEMDAS: 
1. Parentheses: ()
2. Exponent: ^
3. Multiplication: *
4. Division: /
5. Addition: +
6. Subtraction: - 
% for remainder 

```
note: / performs integer division when used with integers. eg: 5/2 = 2
```

### No automatic type coercion 

Rust will not automatically convert a value from one type to another, even if the conversion is lossless

```
eg: 
let b: u8 = 100;
let a: u32 = b;
COMPILER ERROR: mismatched types
```
