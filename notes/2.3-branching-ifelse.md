# if, else, else if
```
let number = 3;
if number < 5 {
    println!("'number' is smaller than 5");
} else if number >= 3 {
    println!("'number' is greater than or equal to 3");
} else {
    println!("'number' is smaller than 3");
}
```

# Booleans 
condition of an if condition: must be of type bool 
boolean: true or false 

## No truthy or falsy values 
If the condition if not a boolean, compiler error 

## Comparison operators 
* ==: equal to
* !=: not equal to
* <: less than
* > : greater than
* <=: less than or equal to
* >=: greater than or equal to

# If/else is an expression 
If/else is an expression, not a statement. They return a value that can be assigned to a variable or used in other expressions

```
let number = 3;
let message = if number < 5 {
    "smaller than 5"
} else {
    "greater than or equal to 5"
};
```
