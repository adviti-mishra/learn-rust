# Loops, part 2: for 

for each element in an iter
```
let mut sum = 0;
for i in 1..=6 {
    sum += i;
}
```
Five types of ranges: 
```
1. 1..5: [1,5)
2. 1..=5: [1,5]
3. 1..: [1, Maximum value of integer type]
// ^ for loops
4. ..5: [Minimum value of integer type, 5)
5. ..=5 [Minimum value of integer type, 5]
```

The extreme values of a range don't have to be integer literals. They can be variables or expresions too! 
```
let end = 5;
let mut sum = 0;

for i in 1..(end + 1) {
    sum += i;
}
```
