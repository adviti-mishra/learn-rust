## Profiles
```
note: Profile is a set of configuration options that can be used to customize the way Rust code is compiled. 
```
Cargo provides 4 built-in profiles: 
1. dev: faster compile-times and better debugging UX, slow performance \
``` iterative development and debugging``` \
```cargo build, cargo run or cargo test```
2. release: slower compile-times, fast performance \ 
``` optimized production build``` \
```cargo build --release or cargo run --release```
3. test: inherits settings from dev profile. It is the default profile used by cargo test. \
```correctness testing``` \
```cargo test```
4. bench: inherits settings from the release profile. It is the default profile used by cargo bench. \
```performance benchmarking```
