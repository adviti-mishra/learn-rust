# Defining variables

```
let a = 42;
```

## Type
either: 
* explicitly specified by the developers
* or, inferred by the compiler

### Explicit 
```
let a: u32 = 42;
```

### Type inference
The compiler tries to infer the type based on the context in which the variable is used
```
let x = 42;
let y: u32 = x;
```

#### limitations 
The compiler sometimes needs a little help to infer the correct variable type. In those cases, you will get a compilation error and the compiler will ask you to provide an explicit type hint to disambiguate the situation.

## Function arguments are variables 

```
fn add_one(x: u32) -> u32 {
    x + 1
}
```
Function arguments must have their type explicitly declared. 

This allows the Rust compiler to understand a function's signature without having to look at its implementation. This boosts the compiler speed! 

## Initialization 
You don't have to initialize a variable when you declare it. 
```
let x: u32;
```

However, you must initialize the variable before using it. 
```
let x: u32; 
let y = x + 1;
BAD: compiler error 
```
