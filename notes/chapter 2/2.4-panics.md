# Panics

A panic is Rust's way to signal that something went so wrong that the program can't continue executing. (an "unrecoverable error") 

eg: divide by zero 

# The panic! macro 
You can intentionally trigger a panic 
```
fn main(){
    panic!("This is a panic!");
    // the line below will never be executed
    let x = 1 + 2;
}
```
